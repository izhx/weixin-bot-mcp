### 纯 IP OAuth 发现排查

本地复现发现兼容性缺口：SDK 规范授权服务器发现地址返回 200 和 S256，末尾斜杠返回 307，双斜杠及根路径资源发现地址返回 404。是否为平台实际失败原因尚未证实。

## 仍需注意的边界

- 桥接侧不过期不等于已经长期验证平台任务期限；仍受平台取消订阅、停用任务或 410 回调影响。
- 主动通知依赖微信有效 context。缺少或明确拒绝 context 时等待本人新来信；不承诺永久无条件推送。
- 文字收发与文字主动通知已通过真人验收；0.2.3 已追加通过微信图片触发 Dot 并识别内容的真人验收。文件、视频和语音仍未重新验收。

Tunnel 连通、账号 ready、自动化测试成功或发送 API accepted 都不单独等于微信与 Dot 闭环通过。后续应按实际观测更新本节。
